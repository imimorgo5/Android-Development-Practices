# Космос

Мобильный справочник по космической отрасли: предстоящие запуски ракет, значимые
события, экспедиции, космические агентства и астронавты.

## Возможности

- На главной - пять категорий: запуски, события, экспедиции, агентства, астронавты.
- Списки элементов на `LazyColumn` - виртуализированное отображение для
  большого количества записей.
- Экран деталей по каждому элементу: разметка на `ConstraintLayout`,
  статистика, описание и справочные поля.
- Загрузка актуальных данных Launch Library 2: состояния загрузки, ошибки и повтора.
- Детальные страницы загружаются отдельными запросами по ID.
- Поиск и фильтрация во всех пяти каталогах выполняются запросами к API. Настройки фильтров сохраняются между запусками.
- Добавление в избранное доступно из карточек всех каталогов; отдельная вкладка
  показывает сохранённые записи офлайн и позволяет удалить их или перейти к деталям.
- Красный бейдж на кнопке фильтров показывает, что применён хотя бы один фильтр.
- Вкладка «Профиль»: ФИО, позывной, фотография и ссылка на портфолио; отдельный
  редактор с выбором фото из галереи или камеры.
- Скачивание портфолио с последующим открытием во внешнем просмотрщике документов.

## Стек

- Kotlin 2.2, Android Compose (Jetpack Compose), Material 3, dynamic color
- Навигация: `navigation-compose` (NavHost, стеки списков с аргументами-идентификаторами)
- DI: Hilt; ViewModel из `androidx.lifecycle` (паттерн MVVM)
- Сеть: Retrofit с suspend API и kotlinx.serialization; корутины (`kotlinx-coroutines`)
- Загрузка изображений по URL: Coil (`coil-compose`)
- Сборка: Gradle + Android Gradle Plugin 9

## Архитектура

MVVM с разделением на представление, домен и данные: экраны наблюдают состояние
`@HiltViewModel`; ViewModel вызывают `SpaceUseCases`. Домен содержит интерфейс
`SpaceRepository` и модели приложения. В data `SpaceRepositoryImpl` запрашивает
ответы через Retrofit `SpaceApi` и преобразует DTO в доменные модели. Неизвестные
поля API игнорируются. Сетевые вызовы выполняются suspend-функциями на
`Dispatchers.IO`. Ошибки сети и HTTP (включая 404 и 429) отображаются с возможностью
повтора.

Базовый адрес API задаётся Gradle-параметром `spaceApiBaseUrl`. По умолчанию
используется сервер для разработки без лимитов (`https://lldev.thespacedevs.com/`).
Чтобы собрать приложение с основным сервером, передайте:

```bash
./gradlew assembleDebug -PspaceApiBaseUrl=https://ll.thespacedevs.com/
```

Основной сервер ограничивает неаутентифицированные запросы.

## Поиск, фильтры и избранное

В каждом списке поиск передаётся в API через `search`; список показывает записи,
возвращённые сервером. Доступные фильтры также передаются только как параметры API:

- Запуски: агентство (`lsp__id`), год (`year`), статус (`status__ids`).
- События: агентство (`agency__ids`), год (`year`), тип (`type__ids`).
- Экспедиции: агентство экипажа (`crew__astronaut__agency`), дата начала
  (`start__gte`), дата окончания (`end__lte`), станция (`space_station`).
- Агентства: страна по трёхбуквенному коду (`country_code`), тип (`type__id`).
- Космонавты/астронавты: национальность (`nationality`), агентство
  (`agency_ids`), статус (`status_ids`).

Сортировка по умолчанию: запуски по дате NET и события по дате в убывающем
порядке, экспедиции по дате старта в убывающем порядке, агентства по количеству
запусков в убывающем порядке, космонавты/астронавты по имени по возрастанию.
Все списки загружают результаты постранично с лимитом до 100 записей на запрос
и объединяют страницы до получения полного набора результатов.
Настройки сохраняются в локальном хранилище Android и восстанавливаются при
следующем открытии раздела. Бейдж отражает активность фильтров; его состояние
хранится в общем singleton-кэше, предоставляемом Hilt, и не записывается на диск.

Избранное реализовано на Room (`space_catalog.db`): из карточки можно сохранить
или удалить запись. В базе хранится сериализованный снимок элемента, а при
успешной загрузке страницы деталей он обновляется полной моделью. При сетевой
ошибке экран деталей использует сохранённую модель, поэтому избранное можно
открывать без интернета. Вкладка «Избранное» показывает офлайн-карточки всех пяти категорий.

## Профиль

В профиле можно указать ФИО, позывной, фотографию и ссылку на
портфолио. Фотография выбирается из галереи или снимается камерой; необходимые
разрешения запрашиваются автоматически с учётом версии Android.

Кнопка «Редактировать» открывает форму: «Готово» сохраняет изменения, а возврат
назад отменяет правки. Данные и копия фотографии хранятся на устройстве и доступны
без интернета, в том числе после перезапуска приложения.

Кнопка «Портфолио» скачивает документ по прямой HTTPS-ссылке и открывает его во
внешнем просмотрщике. Поддерживаются PDF, DOC, DOCX и TXT до 25 МБ. Ошибки загрузки,
отсутствие сети или просмотрщика отображаются в интерфейсе.

## Сборка и запуск

Требуется Android SDK (путь задаётся в `local.properties`).

```bash
./gradlew assemble        # сборка APK (debug в app/build/outputs/apk/debug)
./gradlew test            # JVM-тесты, включая валидацию и use cases профиля
./gradlew :app:lintDebug  # статический анализ
./gradlew :app:connectedDebugAndroidTest # тесты на подключённых устройствах/эмуляторах
```

Либо откройте проект в Android Studio и запустите конфигурацию `app`.

## API

Используемая документация схемы API находится в `app/develop_data/api.json`.
Реализованы списки и детали для запусков (`launches/upcoming`), предстоящих
событий (`events/upcoming`), экспедиций, агентств и астронавтов. Списковые
запросы используют `limit`, `offset`, API-параметры поиска/фильтрации и сортировки;
все страницы загружаются до конца. Для деталей передаётся ID в пути.
